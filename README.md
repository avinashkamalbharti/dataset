# Multiclass Diabetes Dataset (copy)

`diabetes_raw.csv`: 264 patients (96 non-diabetic, 40 prediabetic, 128 diabetic), 11 clinical features (`Gender`, `AGE`, `Urea`, `Cr`, `HbA1c`, `Chol`, `TG`, `HDL`, `LDL`, `VLDL`, `BMI`) and a `Class` label (0 = non-diabetic, 1 = prediabetic, 2 = diabetic).

Used by [Diabetes-biomarker-classification](https://github.com/avinashkamalbharti/Diabetes-biomarker-classification).
